# 리센느 팬게임 🎀

three.js를 **만들면서 배우기**
최종 목표는 브라우저에서 돌아가는 **간단한 웹 게임** 한 편을 끝까지 완성하는 것.

---

## 실행 방법

```bash
pnpm install
pnpm dev        # → http://localhost:5173
```

| 명령어         | 설명                               |
| -------------- | ---------------------------------- |
| `pnpm dev`     | 개발 서버 (저장하면 자동 새로고침) |
| `pnpm build`   | 배포용 빌드 → `dist/`              |
| `pnpm preview` | 빌드 결과 미리보기                 |
| `pnpm lint`    | 코드 검사                          |
