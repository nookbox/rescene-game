# 길건너기 🚗

three.js를 **만들면서 배우기**
Crossy Road 류의 길건너기 게임을 브라우저에서 돌아가게 끝까지 완성하는 것이 목표.

방향키(또는 스와이프)로 한 칸씩 이동하며 차를 피해 앞으로 나아간다.

---

## 실행 방법

```bash
pnpm install
pnpm dev        # → http://localhost:5173
```

| 명령어         | 설명                               |
| -------------- | ---------------------------------- |
| `pnpm dev`     | 개발 서버 (저장하면 자동 새로고침) |
| `pnpm build`   | 배포용 빌드 → `dist/`              |
| `pnpm preview` | 빌드 결과 미리보기                 |
| `pnpm lint`    | 코드 검사                          |
| `pnpm typecheck` | 타입 검사                        |
